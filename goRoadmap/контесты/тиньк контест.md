

## **Задача 1**

Аня и Маша играют в игру «Камни».  
Изначально на доске лежит ( n ) камней.

Игра проходит следующим образом:

- Сначала Аня убирает с доски любое **чётное количество камней** (в том числе может не убирать ни одного).
    
- Если после этого на доске не осталось камней, **Аня сразу выигрывает**.
    
- В противном случае Маша добавляет на доску **любое количество камней** (в том числе может ничего не добавлять).
    

Если игра не завершилась за **3 раунда**, то выигрывает Маша.

**Требуется:** определить, кто выиграет при оптимальной игре.

### Входные данные

Одно целое число ( n ) ((1 < n < 10^5)) — начальное количество камней.

### Выходные данные

Выведите:

- `"Anya"` — если выигрывает Аня
    
- `"Masha"` — если выигрывает Маша

Разрешено выполнять только одно действие:

- дописывать **любое количество букв `a` в начало строки** (включая 0).
    

Строка называется палиндромом, если она читается одинаково слева направо и справа налево.

**Требуется:** определить, можно ли таким способом получить палиндром.

### Входные данные

Строка ( s ), (1 <= |s| <= 10^6) из строчных латинских букв

### Выходные данные

Выведите:

- `"Yes"` — если можно получить палиндром

## **Задача 3**

- Приглашено ( 2n ) человек
    
- Есть ( m ) различных блюд

Выбор блюд называется **интересным**, если никакие два соседних человека не выбрали одинаковое блюдо.

Соседями считаются:

- люди рядом в одном ряду
    
- люди напротив друг друга по разные стороны стола
    

**Требуется:** посчитать количество различных интересных вариантов выбора блюд и вывести его по модулю 10^9 +7

### Входные данные

Два числа:

- ( n ) —  ((1 <= n <= 10^6))
    
- ( m ) — ((1 <= m <= 10^9))
    

### Выходные данные

Одно число — количество интересных вариантов по модулю (10^9 + 7)

## **Задача 4**

Даны цены акции на ( n ) дней.

Разрешено совершить **ровно две сделки с одной акцией

сделкой состоит из:

- Первая: купить в день ( a ), продать в день ( b ), где ( a <= b )

Нельзя держать более одной акции одновременно, а вторая сделка не раньше завершения первой

**Требуется:** найти максимальную суммарную прибыль.

### Входные данные

- ( n ) ((1 <= n <= 5 * 10^5)) — количество дней
    
- массив цен ( p_1, p_2, ..., p_n ) где ((1 <= p_i <= 10^9))
    

### Выходные данные

Одно число — максимальная прибыль

## **Задача 5**

**Ограничение времени:** 1 секунда  
**Ограничение памяти:** 256 МБ

Организаторы «T-Bank Olympiad in Informatics» вводят новый класс строк, используемых в олимпиадных задачах.

Строка называется **TOI-строкой**, если выполняются следующие условия:

- она состоит только из символов **T, O, I**;
- она читается одинаково слева направо и справа налево (является палиндромом).

Дана произвольная строка из **больших букв латинского алфавита**, требуется преобразовать её в TOI-строку.

За одну операцию разрешается выполнить одно из следующих действий:

- заменить один символ строки на другой;
    
- удалить один символ;
    
- вставить один символ в произвольную позицию.
    

Требуется определить минимальное количество операций, необходимых для преобразования данной строки в ТОI-строку.

### Входные данные

В первой строке задано целое число n (1≤n≤1000) — длина строки.  
Во второй строке задана строка s длины n из больших букв латинского алфавита.

### Выходные данные

Выведите одно целое число — минимальное количество операций.

Компания T-Bank планирует нанять a backend-разработчиков и b ML-инженеров. Всего на позиции претендуют n кандидатов, и каждый из них может быть принят либо на позицию backend-разработчика, либо на позицию ML-инженера.

Для каждого кандидата известно:

- \( x \) — уровень backend-навыков  
- \( y \) — уровень ML-навыков  

Каждого кандидата можно назначить только на одну из двух ролей.

Требуется выбрать сотрудников так, чтобы:

- было выбрано ровно \( a \) backend-разработчиков.
- было выбрано ровно \( b \) ML-инженеров.
- каждый кандидат выбран не более одного раза.

При этом нужно максимизировать сумму соответствующих навыков.

### Входные данные

В первой строке заданы \( a,b,n \) (\( 1 <= n <= 2*10^5 \), \( 0 <= a, b <= n ,  a + b <= n \)) — количество backend-разработчиков, ML-инженеров и общее число кандидатов.

Далее следует \( n \) строк, каждая из которых содержит два целых числа \( x \) и \( y \) (\( 0 <= x, y <= 10^9 \)) — соответствующие навыки кандидата.

### Выходные данные

Выведите одно целое число — максимальную суммарную сумму навыков.

# 7 задание  
**100 баллов**

**Ограничение времени:** 1 секунда  
**Ограничение памяти:** 256 МБ  

В музее нумизматики проходит выставка старинных монет. Экскурсовод рассказал Маше, что в Римской Империи использовались монеты \( n \) различных номиналов: \( a_1, a_2, ..., a_n \).  

Известно, что  
\[1 = a_1 < a_2 < ... < a_n\]  
и для каждого \( 1 <= i <= n - 1 \) номинал \( a_{i+1} \) кратен \( a_i \).  

В сувенирной лавке Маша хочет купить вещь стоимостью \( x \). Она может заплатить любую сумму не меньше \( x \), а продавец выдаст сдачу теми же монетами.  

Нужно определить минимальное общее количество монет, которое будет использовано: и тех, которыми Маша платит, и тех, которые она получит в качестве сдачи.

Более формально, среди всех целых \( y >= x \) требуется найти минимум величины (минимальное число монет, чтобы набрать ровно \( y \)) +  
(минимальное число монет, чтобы набрать ровно \( y - x \)).

### Входные данные

В первой строке даны числа \( n \) (\( 1 <= n <= 60 \)) и \( x \) (\( 1 <= x <= 10^{18} \)) — количество монет и необходимая сумма.

В следующей строке даны \( n \) чисел \( 1 = a_1, a_2, ..., a_n \) (\( 1 <= a_i <= 10^{18} \)) — номиналы монет. Для всех \( 1 <= i <= n - 1 \) число \( a_{i+1} \) кратно \( a_i \).

### Выходные данные

Выведите одно целое число — минимальное общее количество монет.
