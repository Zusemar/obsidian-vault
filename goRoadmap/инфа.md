# Блок 5. Задания №19–21: Теория игр (10 минут)

Это **блок из трёх задач с общей легендой** (два игрока, камешки/конфеты, выигрывает тот, кто достигнет N). На них выделяется суммарно 3 балла.

- **№19** — найти значение параметра, при котором **первый** игрок **выигрывает одним ходом**.
- **№20** — первый **проигрывает любым ходом**, второй выигрывает за 1–2 хода.
- **№21** — второй выигрывает независимо от действий первого, но не всегда за 2 хода.

### Метод решения

Рекурсивная функция `wins(s)` — может ли игрок, делающий ход из позиции `s`, выиграть при оптимальной игре.

```python
MOVES = [lambda x: x + 1, lambda x: x * 2]  # пример ходов
N = 47  # выигрышная позиция

def pos_wins(s):
    """True, если игрок, делающий ход из s, может выиграть."""
    if any(m(s) >= N for m in MOVES):
        return True          # выигрыш одним ходом
    return any(not pos_wins(m(s)) for m in MOVES)

def pos_loses(s):
    """True, если игрок, делающий ход, проигрывает при любой своей стратегии."""
    if any(m(s) >= N for m in MOVES):
        return False
    return all(pos_wins(m(s)) for m in MOVES)
```

Дальше — перебором `s` в диапазоне находим ответы на 19, 20, 21.

Кабанов в разборе демо советует **один универсальный шаблон** под все три задания, меняется только формула хода и условие конца игры.

### №23 — Подсчёт числа программ

- **Тема:** исполнитель начинает с 1, должен получить N с набором команд и избеганием «запретной» точки.
- **Метод:** рекурсивная функция с мемоизацией.

```python
from functools import lru_cache

@lru_cache(None)
def paths(x, target, forbidden):
    if x == forbidden:
        return 0
    if x == target:
        return 1
    if x > target:
        return 0
    return paths(x + 1, target, forbidden) + paths(x * 2, target, forbidden)

print(paths(1, 23, 7))  # начиная с 1, в 23, минуя 7
```

### №25 — Обработка целочисленной информации (2 прототипа)

**Прототип А — делители / простые числа.** Дан файл с числами или диапазон, найти числа с заданным количеством делителей, или в заданном интервале найти пары простых чисел, или числа, удовлетворяющие условию на сумму делителей.

```python
def count_divisors(n):
    cnt = 0
    i = 1
    while i * i <= n:
        if n % i == 0:
            cnt += 2 if i * i != n else 1
        i += 1
    return cnt
```

Ключевая оптимизация — перебор делителей **до √N**. Прямой `for i in range(1, n)` падает по времени на больших числах.

**Прототип Б — маски чисел** (появился в демо, активно встречается). Легенда: «Среди натуральных чисел до 10¹⁰ найти все числа, соответствующие маске `3?12?14*5`, делящиеся на 1917 без остатка». `?` = ровно один произвольный символ, `*` = любая последовательность символов (возможно пустая).

```python
from fnmatch import fnmatch

mask = '3?12?14*5'
d = 1917
results = []
for x in range(0, 10**10, d):      # сразу шагом d — только кратные
    if fnmatch(str(x), mask):
        results.append((x, x // d))

# Ответ — обычно последние несколько пар в сортировке по частному
for x, q in results:
    print(x, q)
```

**Формат ответа в прототипе Б:** обычно **5 строк вида `число – частное`** (или как указано в условии). Важно не перепутать порядок чисел в паре и не забыть отсортировать.

### №26 — Обработка целочисленной информации с файлом (до 2 баллов)

- **Тема:** дан файл (`.txt`) с большим количеством данных — координаты, размеры, числа с атрибутами. Надо ответить **парой чисел** в строго определённом порядке.
    
- **Актуальные прототипы (демо-2026 и тренировочные варианты):**
    
    - **«Посылки / яблони / места в ряду»:** даны `(номер ряда, номер места)` занятых точек. Найти ряд **с наибольшим номером**, в котором есть N подряд идущих свободных мест между двумя занятыми. Ответ: два числа — номер ряда и номер первого свободного места.
    - **«Обручи» и аналогичные:** даны размеры (диаметры, массы, длины) объектов. Выбрать наибольший поднабор, в котором соседние по сортировке отличаются не меньше чем на заданный порог. Ответ: количество + параметр последнего выбранного.
- **Метод:** почти всегда три шага: **считать** → **отсортировать по нужному ключу** → **один проход** с обновлением ответа. Полноценного ДП обычно не требуется — задача решается жадностью.
    

```python
# Пример: «посылки» — найти ряд с наибольшим номером,
# где есть ровно K=7 свободных мест подряд между занятыми.
with open('26.txt') as f:
    n = int(f.readline())
    taken = [tuple(map(int, line.split())) for line in f if line.strip()]

taken.sort()                                   # сначала по ряду, потом по месту
K = 7
best_row, best_seat = -1, -1
for i in range(n - 1):
    r1, s1 = taken[i]
    r2, s2 = taken[i + 1]
    if r1 == r2 and s2 - s1 - 1 >= K:          # в одном ряду, зазор ≥ K
        if r1 > best_row:
            best_row = r1
            best_seat = s1 + 1                 # первое свободное после s1

print(best_row, best_seat)
```

- **Критерий на 2 балла:** **порядок двух чисел в ответе критичен** — поменяешь местами, потеряешь 1 балл. Всегда сверяться с формулировкой условия: «в ответе запишите два числа: сначала ... затем ...».
- **Альтернатива на 1 балл:** можно сделать всё формулами в LibreOffice Calc (отсортировать, столбец разностей, фильтр), но на больших файлах и нестандартных условиях программа надёжнее.

### №27 — Кластеризация точек (до 2 баллов)

**Главное и единственное, что сейчас актуально.** С 2025 года и во всей демо-2026 задание №27 — это задача на **кластеризацию точек на плоскости** (обычно «звёзды на карте звёздного неба»). Старые алгоритмические подтипы (магистраль, пары кратности, префиксные суммы, кольцевая дорога) в формате ЕГЭ больше **не встречаются** — если они где-то мелькают, это архив до 2024 года. Готовиться надо только к кластеризации.

**Легенда задачи.** Дан файл A (≤1000 точек) и файл Б (≤10 000 точек). Каждая строка — координаты `x y`. Точки разбиваются на N непересекающихся кластеров (в демо обычно N=2 для A и N=3 для Б). Надо посчитать **одну из характеристик** кластеров и вывести в строго заданном формате (часто «целая часть произведения значения на 10 000»).

**Что спрашивают в разных прототипах (все встречались в 2025–2026):**

- Координаты **центроидов** кластеров (центр кластера = точка, сумма расстояний от которой до остальных минимальна, или среднее арифметическое координат).
- **Px, Py** — среднее арифметическое координат центроидов.
- **dmin, dmax** — минимальное / максимальное расстояние между точками **разных** кластеров.
- **Радиус кластера** — максимальное расстояние от центра до точки кластера.
- **Медианы** / **диагонали** / **среднее расстояние** внутри кластера.
- **Расстояние от заданной точки** (например, (3.0, 3.0)) до центроидов.
- **Обработка аномалий** — точек, которые не попали ни в один кластер.
- **Дополнительные параметры точки** (цвет, тип, светимость) — появились в досрочной волне 2026, могут войти в основную.

**Ключевая формула — евклидово расстояние:**

$$d(A, B) = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$

### Метод 1: DBSCAN (универсальный, работает на любом файле)

Алгоритм: берём неразмеченную точку → находим всех её соседей в радиусе `eps` → если соседей хватает, это новый кластер → рекурсивно «расползаемся» по соседям соседей. Параметр `eps` подбирается так, чтобы получилось ровно N кластеров.

```python
from math import hypot

def load(path):
    with open(path) as f:
        return [tuple(map(float, line.split())) for line in f]

def dbscan(points, eps):
    n = len(points)
    cluster = [-1] * n      # -1 = ещё не в кластере
    cid = 0
    for i in range(n):
        if cluster[i] != -1:
            continue
        # BFS от точки i
        stack = [i]
        cluster[i] = cid
        while stack:
            j = stack.pop()
            for k in range(n):
                if cluster[k] == -1:
                    if hypot(points[j][0] - points[k][0],
                             points[j][1] - points[k][1]) <= eps:
                        cluster[k] = cid
                        stack.append(k)
        cid += 1
    return cluster, cid

points = load("27-A.txt")
# Подбираем eps, пока число кластеров не станет = 2 (или 3 для файла Б)
cluster, n_clusters = dbscan(points, eps=1.0)
print("Число кластеров:", n_clusters)

# Группируем
groups = [[] for _ in range(n_clusters)]
for p, c in zip(points, cluster):
    groups[c].append(p)

# Пример: центроиды как средние арифметические
centroids = [
    (sum(x for x, _ in g) / len(g), sum(y for _, y in g) / len(g))
    for g in groups
]

# Формат ответа: целая часть (Px × 10000), целая часть (Py × 10000)
Px = sum(c[0] for c in centroids) / len(centroids)
Py = sum(c[1] for c in centroids) / len(centroids)
print(int(Px * 10000), int(Py * 10000))
```

### Метод 2: «таблицей» в LibreOffice Calc (для файла А, 1 балл)

На маленьком файле (≤1000 точек) кластеры часто **явно разделены по одной координате** — видно глазами. Тогда:

1. Открыть файл А в Calc как CSV.
2. Построить точечную диаграмму (XY Scatter) — визуально увидеть 2 кластера.
3. Фильтром (например, `x < 5` vs `x ≥ 5`) разделить.
4. Формулами `СРЗНАЧ(A1:A300)` посчитать центроиды, `КОРЕНЬ()` + `СУММ()` — расстояния.

Этого хватает **на 1 балл по файлу А**. Для файла Б (10 000 точек, часто пересекающиеся области) — только DBSCAN.

### Метод 3: Геометрический (когда кластеры — прямоугольники)

В некоторых прототипах гарантируется: кластер помещается в прямоугольник H×W, прямоугольники разных кластеров не пересекаются. Тогда можно обойтись без DBSCAN — отсортировать точки по x, найти «разрыв» больше W, этим разрывом разделить.

### Важные детали формата ответа

- Ответ — **несколько чисел в строгом порядке**, обычно: сначала результат для файла А, потом для файла Б.
- Часто просят «целую часть произведения на 10 000» — это защита от округлений. Используй `int()` в Python, **не** `round()`.
- Формат разделителя (пробел / новая строка) всегда указан в условии — не ошибись, иначе балл не засчитают.
